System architecture

Everything except DNS and S3 lives on one Lightsail instance. Only ports 22, 80 and 443 are open; PostgreSQL listens on localhost only.

Request path

Nginx picks the route from the URL path. Pages and assets come from the frontend; /api calls go to the backend, which is the only part that talks to the database.

Deployment

Once Docker is installed, one script syncs the repository to the instance and brings up all four containers with Docker Compose.

  1. Install Docker

    SSH into the instance and install Docker Engine for Ubuntu.

  2. Add environment files

    Create the .env files in env/database/, env/backend/ and env/aws/.

  3. Run the deploy script

    Run deploy-lightsail.sh to sync the repository and start the containers.

  4. Check the containers

    Run docker ps and confirm all four containers are up.

  5. Test the endpoints

    Open ecommerce.harshildex.com and backend.ecommerce.harshildex.com.
